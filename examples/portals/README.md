# Portals

Apps used by customers or partners from outside the company.

Planned:

- account-self-service
- claims

## Why

- Customer service is the top agent use case, at 26.5% ([LangChain, State of Agent Engineering](https://langchain.com/state-of-agent-engineering)). Klarna, Lyft and Included Health let the agent act on the customer's own account ([LangChain customers](https://langchain.com/customers)).
- 78% of property and casualty insurers have adopted generative AI, but only 4% have scaled it in claims ([Bain via Insurance Business, Dec 2025](https://www.insurancebusinessmag.com/uk/news/technology/most-pandc-insurers-still-on-pilot-mode-with-gen-ai-bain-and-company-560261.aspx)).
- Internal use still leads external use, 66% to 43% ([Retool, 2023](https://businesswire.com/news/home/20231113269390/en)), so portals come after internal tools.
