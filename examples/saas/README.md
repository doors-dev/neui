# SaaS products

Multi-role products where the agent works for each customer's users.

Planned:

- analytics
- merchant-admin
- crm

## Why

- Research and data analysis is 24.4% of agent use cases ([LangChain, State of Agent Engineering](https://langchain.com/state-of-agent-engineering)), and BI is the most targeted product use case ([ICONIQ, State of AI 2026](https://www.iconiq.com/growth/reports/state-of-ai-2026)).
- The common SaaS pattern is an agent that operates the product for its users: AppFolio ([LangChain customers](https://langchain.com/customers)), Shopify Sidekick, Reactiv ([2026-06-08](https://reactiv.ai/post/how-we-used-copilotkit-to-power-1-1-ai-operations-in-the-reactiv-dashboard)) and Teamworks ([Mastra customers](https://mastra.ai/customers)).
- CRM has named adopters such as Apollo and Clay ([LangChain customers](https://langchain.com/customers)), with less survey support.
