# Internal tools

Tools a company's own staff use for support and IT.

Planned:

- support-console
- ops-console

## Why

- IT is where companies use agents most ([McKinsey, State of AI 2025](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai-2025)), and IT is second by department spend ([Menlo Ventures, 2025-12-09](https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise/)).
- Over a third of Go developers build cloud infrastructure tooling ([Go Developer Survey 2025](https://go.dev/blog/survey2025)).
- Customer service is the top agent use case, at 26.5% ([LangChain, State of Agent Engineering](https://langchain.com/state-of-agent-engineering)).
